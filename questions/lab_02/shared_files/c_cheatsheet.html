3 switch-case
switch (ch) {
  case 'A':
    printf("Add");
    break;        // ← must!
  case 'D':
    printf("Del");
    break;
  default:
    printf("?");
}

⚠ No break → fall-through!

4 Functions — 4 Styles
Type 1 No arg, No return 
void greet(void) {
  printf("Hi!");
}
greet();     // call
Type 2 With arg, No return 
void printSq(int n) {
  printf("%d", n*n);
}
printSq(5);
Type 3 No arg, Returns value 
int getNum(void) {
  return 10;
}
int x = getNum();
Type 4 With arg + return 
int add(int a, int b) {
  return a+b;
}
int z = add(3,4);
5 Declare → Call → Define
// DECLARATION (before main)
int add(int, int);

int main() {
  // CALL / INVOKE
  int r = add(10,20);
}

// DEFINITION (after main)
int add(int a, int b){
  return a+b;
}

9 Compile & Quick Checklist
gcc program.c -o program
./program

# with warnings (recommended):
gcc -Wall -Wextra program.c -o prog
  • ✅ Included correct header file?
  • ✅ Declared all variables?
  • ✅ Function prototype before main()?
  • ✅ Used == for comparison (not =)?
  • ✅ All { } and ( ) matched?
  • ✅ Semicolons ; after each statement?
  • ✅ & before variables in scanf()?
  • ✅ break in each switch case?
  • ✅ Every non-void function returns a value?
